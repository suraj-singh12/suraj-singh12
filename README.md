## 🚀 Featured projects

### [SentriFace Edge](https://github.com/suraj-singh12/sentri-face-edge)

**Face identification that stays on your computer.**

Run face identification without internet or a GPU, review proposed matches before saving identity decisions, and keep records in encrypted local storage.

### [GNSS Android Tracking](https://github.com/suraj-singh12/gnss-android-tracking)

**Field tracking without internet, SIM cards or cloud services.**

Connect Android devices to a local command dashboard over Wi-Fi. Record tracks, calculate travelled distance, view offline maps and receive SOS alerts—with observations retained locally during connection loss.
